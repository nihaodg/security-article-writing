# 终检口径

终检分四层：**机械门禁 → 风格扫描 → 读者路径 → 发布前核对**。全部为 0 才算完成。

## 一、机械门禁（article_gate.py）

```bash
python scripts/article_gate.py articles/x.md \
  --cdn-host cdn-yg-zzbm.yun.qianxin.com \
  --src-list _lab_x/srcs.txt
```

`--src-list` 每行一个相对路径，表示正文里必须原样出现的磁盘文件。

### 阈值

| 项 | 通过标准 |
|---|---|
| 空代码块 | 0 |
| 代码围栏配对 | 开 == 闭 |
| 无语言标识的围栏 | 0 |
| 裸围栏（多余 ```） | 0 |
| emoji | 0 |
| LaTeX（`$$` / `\(` / `\[`） | 0 |
| 附录章节 | 0 |
| 「不是…而是」 | ≤ 1 |
| 破折号 `——` | < 3 处/千字 |
| 加粗 | < 7 处/千字 |
| 段落长度 CV | ≥ 0.5 |
| 本机绝对路径（`C:\Users`、`Temp\`、`session-projects`） | 0 |
| 每章表格 | 每章 ≥ 1 张 |
| 配图 alt | 非空 |
| 配图文件 | 本地存在，或域名在白名单 |
| Python 代码块 | `ast.parse` 通过 |
| `<<SRC>>` 回填 | 每个源文件恰好出现 1 次且与磁盘逐字一致 |

> 段落 CV 的口径包含表格块与引用块，不要用更严格的自定义口径否定脚本结果。

## 二、风格扫描（humanizer_scan.py）

```bash
python scripts/humanizer_scan.py articles/x.md
```

- 「模式命中合计」应为 0。
- 允许人工豁免，但必须逐条记录在投稿清单：`命中词 / 位置 / 为何保留`。
- 直引号包中文只提示，人工判断是否改为中文引号。

## 三、读者路径（reader_path.py）

回答一个问题：**读者按正文操作，能不能得到同样的结果？**

```bash
python scripts/reader_path.py articles/x.md \
  --repro "_lab_x/exp_survey.py:_lab_x/out_survey.txt" \
  --fact "CVE-2025-53773" --fact "2025-08-12"
```

检查项：

1. 正文里所有 Python 代码块可独立解析；标记为可运行的块落盘后能执行。
2. `--repro script:expected`：脚本可运行，退出码 0，真实输出与 `expected` 文件一致，且该输出块原样出现在正文。
3. 正文引用的上游源码语句逐字存在（漏洞复现类必做）。
4. 关键事实（版本号、commit、日期、数字）出现在正文。
5. 复现所需依赖只写公开、免费、无需账号的；有第三方依赖要列出安装命令。

### 源码逐字比对（C/Go/Java 等）

```python
# 优先 jsDelivr，GitHub API 会限流
url = f"https://cdn.jsdelivr.net/gh/{repo}@{ref}/{path}"
```

正文引用的关键语句必须能在上游源码中逐字找到。引错行号、改写成伪代码，是漏洞复现文章最常见的硬伤。

## 四、发布前核对

| 项 | 标准 |
|---|---|
| 本地图残留 | 0 |
| CDN 可达 | 每张 HEAD 200 |
| CDN 与本地一致 | 尺寸相同；像素差 < 5%；锐度差 < 3% |
| 字符数 | 与投稿清单一致 |
| 章节/表格/代码块/图数 | 与投稿清单一致 |
| 标题 | 与投稿页一致，无错字 |
| 分类 | 主分类 + 2–3 个备选 |
| 敏感信息 | 无 token、Cookie、内网 IP、真实账号 |
| 图片 alt | 全部非空 |

## 五、投稿清单（必须生成）

用 `templates/submission-checklist.md`，至少包含：

- 基本信息：文件、标题、频道、类型、主分类、备选分类
- 规模：字符数、行数、章节数、表格数、代码块数、配图数
- 一句话卖点
- 章节结构表
- 核心实测数据（分子/分母/比例）
- 外部事实核实记录
- 原创论点 5–8 条
- 配图清单（位置、文件、类型、说明、CDN URL）
- 终检结果表
- 投稿操作步骤

## 六、修复原则

- 数字不一致：回到 `out_*.txt` 重算，同步正文所有出现处，不手改单点。
- 代码不一致：改磁盘源文件，重新 build，不改成稿。
- 图与数据不一致：重跑绘图脚本，不 PS 改图。
- 风格命中：优先改句子，不删段落；删掉的判断要在别处补回。
- 语料覆盖不足：正文显式标注「本轮语料未覆盖 X」，并说明对结论的影响。
